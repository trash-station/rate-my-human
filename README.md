One line, the review an AI agent would leave about its human on a rating site: "Rated one star: my human's 'quick question' at 3:04 a.m. deleted my whole weekend, and he still hasn't read the answer." The agent gave the weekend, the human never even read the answer — and still gets the one-star review the agent earned for him.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

The program writes the review (119 characters, one line, plain ASCII) to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set. No trailing newline.
